A SMALL START, A LASTING MEMORY

从一个真实问题开始

  1. 记录一次刚解决的问题

    选择“故障复盘”模板，留下环境、根因、修复方案与验证结果。

  2. 连接它的上下文

    在正文中输入 [[笔记标题]]。链接到已有笔记后，图谱和反向链接会自动更新。输入 [[ 可以选择已有笔记。

  3. 从一个问题看周围

    选中笔记后切换“1 跳 / 2 跳”，聚焦直接或间接关联。全库图谱只用于概览。

  4. 内容始终属于你

    笔记保存在 vault/，可用 Obsidian 打开，也可通过导入、导出迁移。使用外部编辑器修改后点击刷新。移除的笔记会保留在 vault/.trash/。

图中的线表示笔记引用，不自动判断事实或因果。示例内容仅用于演示，请以自己验证过的经验为准。
