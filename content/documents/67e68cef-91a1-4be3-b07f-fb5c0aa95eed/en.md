This little site now has an address: **henryweb.site**.

I plan to use it to record programming lessons, the problems I run into, and how I eventually solve them. It will also be a home for personal projects and notes worth keeping.

## Start small

The first version covers the basics: reading articles, browsing the archive, and opening projects. The details can improve as I use it.

- **Articles** contain technical notes, investigations, and occasional personal updates.
- **Projects** show what I am building and how it changes.
- **Knowledge graph** is a private workspace for organizing related Markdown documents.

## Keep the process

A solution can feel obvious when it finally works. Months later, the same problem may send me searching again.

Writing down the process should make the next visit easier. Perhaps one of these notes will also help someone else.
