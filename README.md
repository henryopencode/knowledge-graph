# DevGraph · 开发者知识库

把项目背景、故障复盘、技术决策和知识概念保存为 Markdown，通过链接连接起来。

## 启动

需要 Python 3.10 或更新版本，不需要安装第三方依赖。

```sh
python3 server.py
```

在浏览器访问 <http://127.0.0.1:8765>。服务只监听本机，按 `Ctrl+C` 停止。

```sh
# 端口被占用时
python3 server.py --port 8766

# 打开已有的 Markdown 知识库；不会自动写入示例
python3 server.py --vault /absolute/path/to/your/vault
```

## 第一次使用

1. 知识库从自己的笔记开始，不会自动添加演示内容。左侧按分类浏览，例如“前端”；分类可以在新建或编辑笔记时填写。
2. 点击「新建笔记」，选择类型，使用模板记录一个真实问题；填写环境、证据、根因、处理与验证。
3. 在正文中输入 `[[笔记标题]]`。输入 `[[` 后可以选择已有笔记；保存后自动建立图谱关系和反向链接。
4. 搜索支持标题、分类、正文和标签；点击左侧分类名称筛选，类型下拉框和标签可进一步缩小范围。“全部笔记”清除筛选。
5. 点击节点查看内容；右侧面板的「全屏」可以进入大字号阅读，按 Esc 或点击返回即可退出。全屏中也可跳转关联文档和编辑。切换 1 跳 / 2 跳查看局部关系，拖动画布或滚轮缩放。
6. 点击右上角「导入文档」，选择或拖入 `.md`、`.markdown`、`.txt` 文件。每个文件不超过 500 KB，每次最多 50 个、合计 2 MB。同名文件不会被覆盖；部分失败会列出原因。PDF 和 Word 需要先转换格式。左下角可导出 ZIP 备份。

界面采用以图谱为中心的工作区：左侧文件树、中间全屏画布、右侧按需展开的笔记 / 链接面板。最左侧工具栏可收起目录、切换图谱和列表、新建笔记或切换明暗主题；上方显示设置可调整着色、连线与节点间距。

## 文件与你的数据

```text
vault/
  01-项目/       项目目标、模块边界与运行方式
  02-故障/       现象、排查、根因、修复与验证
  03-决策/       背景、候选方案、选择与代价
  04-知识/       概念、实验、应用与参考
  .trash/        移除的笔记，可手动移回原目录恢复
templates/       四种可复制的 Markdown 模板
web/             本地界面
server.py        文件存储、链接解析和本机 HTTP 服务
tests/           文件与 API 集成测试
```

所有笔记保存在磁盘上，刷新页面、清除浏览器数据不会删除笔记。界面不向第三方服务上传内容，不需要 AI API 或外部脚本。

可以在 Obsidian 中将 `vault/` 作为库打开，使用同一份文件。外部修改后在 DevGraph 点击刷新。编辑保存时会检查文件版本，避免静默覆盖其他编辑器的修改。为保持已有链接，网页编辑器不重命名标题；重命名请使用 Obsidian，并确认其「自动更新内部链接」设置。

移除会把文件放到 `.trash/`，不会改写引用它的其他笔记。备份包含当前 Markdown、回收目录和模板；导出不包含浏览器设置或应用源码。恢复时解压，将文件复制到对应目录并刷新。

## Markdown 与链接规则

支持标题、段落、列表、引用、代码块、简单表格、加粗、斜体、外部链接与 `[[内部链接]]`。不执行原始 HTML，不加载外部图片。

笔记元信息使用 YAML 兼容的简单 frontmatter：

```markdown
---
title: "我的故障复盘"
kind: "incident"
category: "后端"
tags: ["后端", "性能"]
created: "2026-10-19T09:00:00+08:00"
updated: "2026-10-19T09:00:00+08:00"
---

## 现象

所属项目：[[我的项目]]
```

`kind` 可为 `project`、`incident`、`decision`、`concept`，表示笔记类型。`category` 是独立的领域分类，例如“前端”，可留空；缺少分类的旧笔记显示在“未分类”，已有文件路径和内部链接保持有效。不带 frontmatter 的文件也能读取，默认按知识概念处理。支持简单标量、字符串数组和多行标签列表；其他复杂 YAML 字段不作解释，网页编辑保存时保留原文。

链接可用标题、文件名或库内路径，例如 `[[01-项目/我的项目]]`；支持 `[[我的项目|显示名称]]` 和 `[[我的项目#小节]]`，小节链接目前跳转整篇笔记。代码块与行内代码中的链接不参与图谱。重名目标不会被任意连接，可用完整路径消除歧义。当前不把普通 Markdown 文件链接、标签或附件解析为图谱关系。

全库视图以无向连线概览关系；方向在详情中的「链接到 / 被这些笔记引用」区分。圆点大小按不同关联笔记数变化，不代表内容正确性。大库图谱最多显示筛选结果的前 120 篇，完整内容可通过搜索和笔记列表访问。

## 验证

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
```

默认是本地服务。服务器部署参见 [部署说明](deploy/README.md)，通过带访问控制的 Nginx 代理访问，内容保存在服务器磁盘。当前不提供多人协作、AI 自动提取或自动云同步。需要版本管理时可自行初始化 Git；请先排除含个人信息的日志和敏感文件，再选择备份位置。
