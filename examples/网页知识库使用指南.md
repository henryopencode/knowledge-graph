## 全屏阅读文档

在文件目录或关系图谱中选中一篇文档，点击右侧面板上方的“全屏”。文档会铺满阅读区域，正文使用更大的字号和更舒适的行距。

阅读时仍可点击文档中的内部链接，跳转到相关记录。左上角的“返回图谱”或键盘上的 Esc 可以退出全屏。

## 上传已有文档

1. 点击右上角的“导入文档”。
2. 选择 Markdown 或 TXT 文件，也可以把文件拖入导入窗口。
3. 导入后，在左侧目录中找到文档并打开。

支持的扩展名是 .md、.markdown、.txt。每个文件最多 500 KB，每次最多 50 个文件、合计 2 MB。PDF 和 Word 文档需要先转换成 Markdown 或 TXT。

## 建立关联

在正文中用内部链接连接其他笔记。例如，这篇指南关联到 [[我的开发知识库]]、[[知识记录约定]] 和 [[服务器部署记录]]。

代码示例里的链接不会参与图谱：

```markdown
[[这是格式示例，不会创建关联]]
```

## 保存和备份

上传和编辑的内容保存在服务器的知识库目录中，关闭浏览器不会删除文档。左下角的导出图标可以下载 Markdown 备份。

同名文档不会被导入覆盖，需要修改时请打开已有文档并点击“编辑”。
