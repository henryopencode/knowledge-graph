## 本集是导学，不是具体 API 证明

课程将 Vue 部分分成设计理念、响应式、组件基础、路由、状态管理与编译更新几个层次。复习时应把“怎样调用 API”与“为什么这样设计、哪些边界会改变结果”分开记录。

## 建议建立的主线

1. 知道渐进式框架与声明式 UI 的目标。
2. 理解 ref、reactive、computed、watch，以及代理、依赖收集和调度。
3. 把状态放进组件生命周期，处理清理、props、事件与插槽。
4. 根据页面导航、共享状态需要选择 Router 与 Pinia。
5. 再理解模板编译、虚拟 DOM、diff 与 nextTick。

## 贯穿后续的自测问题

为什么 ref 在脚本里常用 .value？为什么 reactive 的原始值属性解构后不是持续连接？组件事件、共享状态和路由各处理什么问题？修改响应式值后为什么不一定立刻读到新 DOM？

这些问题应通过小例子与运行条件回答，而不是只背一行定义。本套笔记以后续实际核对结论为准，视频中存在不准确表述时会保留纠错说明。

## 版本范围

本段主要讨论 Vue 3。遇到 Vue 2 的数组限制、Vue 3.5 的 props 解构与清理 API 等，应明确版本，避免跨版本混用。

本集未提供足够具体的技术断言需要纠正；其中领取资料等推广内容不作为知识结论或需要执行的操作。
